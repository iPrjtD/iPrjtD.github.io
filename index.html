yt-agent

A personal content assistant for a single YouTube channel.

What it does

  • Researches publicly available trending topics.
  • Helps write scripts and produce videos for the owner's own channel.
  • Uploads videos to that channel as private drafts so the owner can review them in YouTube Studio.
  • Publishes only the videos the owner approves, and reads the channel's own analytics to improve future videos.

Who can use it

yt-agent is not a public service. It runs on its owner's computer and is used only with the owner's own Google account and YouTube channel. No one else's data is accessed.

Google and YouTube data

yt-agent uses YouTube API Services. How it handles data is described in the privacy policy.
